📋 Project Overview

This technical journal documents my journey implementing, securing, and evaluating a Linux server operating system across 7 weeks. The project involves deploying a headless Ubuntu Server 26.04 LTS, administering it exclusively via SSH from a Windows workstation, implementing industry-standard security controls, and conducting systematic performance analysis.


The dual-system architecture mirrors real-world cloud infrastructure, developing authentic command-line proficiency and professional remote administration skills.

🎯 Learning Outcomes

LO3 — Security Assess security vulnerabilities and apply appropriate mechanisms to protect systems from exploits.
LO4 — CLI Proficiency Demonstrate proficiency with command-line tools for process monitoring, file manipulation, and system configuration.
LO5 — Critical Evaluation Critically evaluate OS design trade-offs, synthesising knowledge of hardware constraints, performance, and security.

🖥️ System Architecture

Server (Ubuntu VM)

  • Ubuntu Server 26.04 LTS (headless)
  • SSH access only — no desktop environment
  • IP Address: 192.168.1.66
  • RAM: 3.3GB | Disk: 25GB

Workstation (Windows Host)

  • Windows 10/11 host machine
  • PowerShell OpenSSH client
  • VirtualBox for VM management
  • Remote administration via SSH
